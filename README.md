# Proyecto Final - Análisis de Datos

Este es un proyecto de **Análisis de Datos**, desarrollado como proyecto final del curso.

## Equipo

- Santiago Rodríguez
- Juan José Herrera

## Estructura del repositorio

```
.
├── data/
│   ├── bronze/      # Datos crudos, tal como se ingieren desde la fuente
│   └── silver/      # Datos limpios y estandarizados
└── transformacion/  # Scripts y notebooks de transformación de datos
```

### Capas de datos

| Capa   | Descripción                                                                 |
|--------|-----------------------------------------------------------------------------|
| Bronze | Datos en bruto sin procesar, conservados en su formato original.           |
| Silver | Datos depurados: sin duplicados, con tipos corregidos y esquema unificado. |

## Objetivo

Aplicar el proceso de análisis de datos (ingesta, limpieza, transformación y
exploración) sobre el conjunto de datos seleccionado por el equipo para obtener
hallazgos y conclusiones.
